# 企业差异化五险一金计算器

基于产品需求文档整理的静态 MVP。项目当前无需构建，直接打开 `index.html` 即可使用，也适合后续部署到 GitHub Pages。

## 需求总结

需要做的是一个面向香港居民赴内地工作场景的综合薪酬工具，核心不是普通的「工资到手」计算器，而是同时覆盖：

- 员工视角：税前收入、五险一金扣除、个税估算、预计到手收入。
- 企业视角：企业社保、公积金、工伤、生育等用人成本。
- 城市差异：深圳、广州、上海、北京之间的政策基数和费率对比。
- 香港场景：HKD/RMB 换算、港澳居民身份提示、内地直接招聘和派驻场景提示。
- 企业差异：企业类型、规模、行业影响，其中行业会影响工伤费率，企业规模和高新属性预留到税务模型。

## 当前已实现

- 单页输入区：月薪、币种、汇率、城市、公积金比例、行业、企业类型、企业规模、身份场景。
- 计算结果区：税前 RMB、员工预计到手、企业月度成本、企业年度成本。
- 拆分明细：员工养老、医疗、失业、公积金；企业养老、医疗、失业、工伤、生育、公积金。
- 城市比较：保持同一收入和行业条件，切换城市政策后比较到手收入和企业成本。
- 香港专属：支持 HKD 输入并按自定义汇率换算为 RMB。
- 企业税务：提供企业所得税简化估算，高新企业、小微企业、一般企业分别使用不同税率档。
- 政策数据库：以可配置对象保存四个城市的基数、费率、公积金范围和工伤行业档位。

## 使用方式

1. 打开 `index.html`。
2. 输入薪资和币种。如果薪资是 HKD，先确认「1 HKD = ? RMB」的汇率。
3. 选择工作城市和对比城市。
4. 调整公积金比例、行业和企业属性。
5. 查看员工到手、企业成本、城市差异和身份提示。

## 数据口径说明

这是 MVP 估算工具，不是最终上线政策库。上线前建议再核对一次各城市当年官方公告，尤其是年度缴费基数、公积金上下限、阶段性降费政策和工伤行业档位。
